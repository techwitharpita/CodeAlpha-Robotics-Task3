Project Description

This project focuses on a smart home lighting system using PIR (Passive Infrared) and LDR (Light Dependent Resistor) sensors. The system detects human presence and measures ambient light to control lighting automatically.

Objectives

- Detect human movement using a PIR sensor.
- Measure surrounding light intensity using an LDR sensor.
- Automatically control lights based on movement and lighting conditions.
- Reduce unnecessary electricity consumption.

Technologies and Components

- PIR Sensor
- LDR Sensor
- Microcontroller (as required by the project)
- Lighting system
- Embedded programming (as applicable)

Expected Outcome

The system automatically switches lighting according to human presence and ambient brightness, improving convenience and energy efficiency.

Conclusion

A PIR- and LDR-based smart lighting system demonstrates how sensors and automation can help create an energy-efficient smart home.
